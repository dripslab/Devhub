# Stellar Glossary

Use this glossary as a quick reference for the words you will see while building on Stellar.

## Anchor

An anchor is a business or service that connects Stellar to money or assets outside the network, such as bank deposits, cash payouts, or regulated stablecoins.

## Asset

An asset is anything represented on Stellar. XLM is the native asset, while issued assets can represent things like dollars, euros, points, or project tokens.

## Distributor

A distributor is an account that receives an issued asset from the issuer and sends it to users. Teams often use a distributor so the issuer account can stay locked down.

## Horizon

Horizon is Stellar's API service. Apps use Horizon to read ledger data, load accounts, build transactions, and submit transactions to the network.

## Issuer

An issuer is the account that creates an issued asset on Stellar. The issuer controls the asset's supply and trust settings.

## Keypair

A keypair is a matched public key and secret key. The public key identifies an account, and the secret key signs transactions for that account.

## Ledger

A ledger is one confirmed update to Stellar's shared record of accounts, balances, offers, and other network data.

## Mainnet

Mainnet is the live Stellar network where real XLM and real issued assets move. Mistakes on mainnet can have real financial consequences.

## Operation

An operation is one action inside a transaction, such as creating an account, sending a payment, changing account settings, or creating a trustline.

## SEP

SEP stands for Stellar Ecosystem Proposal. SEPs are shared standards that help wallets, anchors, exchanges, and apps work together.

## Soroban

Soroban is Stellar's smart contract platform. Developers use it to build programmable apps that run on Stellar.

## Testnet

Testnet is Stellar's testing network. It uses test XLM with no real-world value, so developers can build and experiment safely.

## Transaction

A transaction is a signed request to change the ledger. It can include one or more operations and succeeds only if every operation inside it succeeds.

## Trustline

A trustline is an account's opt-in to hold a specific issued asset. It tells Stellar that the account trusts that asset's issuer up to a chosen limit.

## XLM

XLM, also called lumens, is Stellar's native asset. It is used to pay network fees, meet minimum balance rules, and transfer value.
